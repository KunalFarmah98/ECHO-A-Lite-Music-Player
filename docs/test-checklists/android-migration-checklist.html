Common Smoke Tests (run on at least one device/emulator per ABI)

  • — expected: installs without signature or manifest errors
  • — expected: app opens, no crash, initial screen visible
  • — expected: audio plays, pause/stop works, no skipping
  • — expected: playback continues or behaves per spec (notification + controls)
  • — expected: play/pause/seek respond correctly from notification
  • — expected: route switches, pause on disconnect
  • — expected: permission prompts appear when needed; app handles denial/grant
  • — expected: UI stable; playback unaffected
  • — expected: graceful error or retry; no crash
  • — expected: state preserved, no unexpected restarts
  • — expected: no excessive memory spikes or battery drain during short smoke test
  • — expected: no fatal uncaught exceptions

Android 7 (API 24/25)

  • — expected: no manifest or permission regressions
  • — expected: service starts/stops as before (verify playback service lifecycle)
  • — expected: handles duck/abandon correctly

Android 10 (API 29)

  • — expected: app reads/writes media as intended or uses SAF if required
  • — expected: prompts and behavior match app policy

Android 12 (API 31)

  • — expected: any foreground service-based playback remains allowed and shows notification
  • — expected: no unexpected permission prompts or blocking UI

Android 14 / 15 (API 34 / 35)

  • — expected: deep links and share intents still work
  • — expected: background jobs and scheduled tasks behave per policy

Android 16 / 17 (latest)

  • — expected: no new crashes; UI layout acceptable
  • — expected: app either adapts or degrades gracefully

Notes & Reporting

  • Record device/emulator model, API level, build variant, and reproduction steps for any failure.
  • If a blocker is found, add a follow-up todo in the session and include logcat, steps, and a screenshot.
  • Target: run Common Smoke Tests on at least one device per major API group and run version-specific tests on at least one device/emulator per listed API.
